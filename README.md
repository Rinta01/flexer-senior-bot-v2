# Флексер старший - Telegram бот для управления дежурными

![Python](https://img.shields.io/badge/Python-3.12+-blue)
![aiogram](https://img.shields.io/badge/aiogram-3.24+-green)
![License](https://img.shields.io/badge/License-MIT-yellow)
![Tests](https://img.shields.io/badge/Tests-98_passing-success)

Telegram-бот для управления ротацией дежурных в дружеских группах. Ручное назначение, система подтверждений, управление активностями и полный цикл без повторений.

## 📖 Основные команды

| Команда                 | Описание                                 |
| ----------------------- | ---------------------------------------- |
| `/join`                 | Присоединиться к пулу дежурных           |
| `/leave`                | Выйти из пула дежурных                   |
| `/pool`                 | Показать список участников               |
| `/pick`                 | Выбрать дежурного случайно на неделю     |
| `/force_pick`           | Назначить конкретного пользователя       |
| `/activity`             | Показать дежурного и активность недели   |
| `/set_activity`         | Установить мероприятие (только дежурный) |
| `/history`              | История последних 10 дежурств            |
| `/help`                 | Полная справка по всем командам          |

## 🎯 Ключевые возможности

- ✅ **Ручное назначение** - `/pick` (случайно) или `/force_pick` (выбор пользователя кнопками)
- ✅ **Система подтверждений** - Дежурный принимает или отказывается через кнопки
- ✅ **Умная ротация** - Гарантия отсутствия повторений в цикле
- ✅ **Управление активностями** - Дежурный устанавливает мероприятие на неделю
- ✅ **Планирование** - Назначение дежурных на несколько недель вперед
- ✅ **Безопасность** - Только подтвержденный дежурный может устанавливать активность
- ✅ **Полное покрытие тестами** - 98 тестов

## ⚡ Быстрый старт

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/Rinta01/flexer-senior-bot-v2.git
cd flexer-senior-bot-v2

# Создать виртуальное окружение и установить зависимости
python3.12 -m venv venv
source venv/bin/activate  # Linux/Mac
pip install -e ".[dev,db]"

# Настроить конфигурацию
cp .env.example .env
# Отредактировать .env и установить BOT_TOKEN

# Запустить
python -m src.bot
```

### Docker (рекомендуется)

```bash
cp .env.example .env
# Установить BOT_TOKEN в .env
docker-compose up -d
```
